§2 TS-E2E-LEN-JSONPATH: kubectl go-template len works; jsonpath len never did (empirical)
------------------------------------------------------------------------------------------
$ kubectl create configmap test-cm --dry-run=client -o go-template='{{len .}}'

$ kubectl create configmap test-cm --dry-run=client -o jsonpath='{len(.)}'
  error: error executing jsonpath "{len(.)}": Error executing template: unrecognized identifier len
(kubectl v1.37.0 client; same engine family as the pinned CI kubectl. `len` is a text/template
builtin used verbatim by -o go-template; it has never been a k8s.io/client-go jsonpath function.)
At head, the cooldown-reset poll uses `-o go-template='{{len .items}}'` (test.sh:548), so the
items_len >= 2 disjunct is live for the first time. Both branches remain fail-safe on an empty
result (|| true -> "" -> ${items_len:-0} = 0 -> keeps polling -> panic at 60 s).
